Seat Watch is installed

A big release is never as sold out as it looks. Cinemas hold seats back — for distributors, for staff, for whoever might still call — and when nobody calls, those seats go back on sale. Often in the last hours before the show, sometimes minutes before it.

Nobody announces it. The page just quietly changes, and by the time you think to look again the good rows are gone. This sits on that page for you and tells you the moment it happens.

The other reason to use it is simpler: you want that screen. The one with the right sound, the right rake, the seats you'd actually choose. A ticket somewhere else isn't the same evening out.

  1. Find a show on BookMyShow

    Open a cinema's showtimes page — the one listing every film and time. Every showtime picks up a small + in its corner.

  2. Click the + on the shows you want

    Including the sold-out ones. A greyed-out showtime is exactly the case this is for: its blocked seats may be released later, and BookMyShow's own sold-out flag is often behind the real seat map.

  3. Leave Chrome running, and awake

    Checks get more frequent as showtime approaches — every 30 minutes a week out, every 90 seconds in the last three hours. You'll get a desktop notification, and Telegram or a webhook if you set one up.

    A sleeping machine checks nothing. The release you're waiting for usually lands late in the evening, which is exactly when a laptop is most likely to have nodded off. See below.

One thing that will look odd

A small BookMyShow window may open in a corner of your screen and stay there. That's the watcher. Leave it on screen — behind other windows is fine, minimised is not. BookMyShow only draws the seat map when its page is visible, so a hidden window reads nothing. If you already have the seat map open yourself, that tab gets used instead and no window appears at all.

Keep the machine awake

Nothing runs while the machine sleeps, and you find out afterwards. Keep the display on too: Chrome treats a window it thinks nobody can see much like a minimised one, and a dark screen can be enough. Plug in first — both recipes below assume it.

macOS

Run this in Terminal and leave the window open. Ctrl-C ends it, and so does closing the window — nothing is left switched on afterwards.

caffeinate -dis

Or, without the Terminal: System Settings → Lock Screen, set Turn display off on power adapter when inactive to Never, and check Battery → Options for Prevent automatic sleeping.

Closing the lid still sleeps a Mac, whatever else you set — unless a display, or power and an external keyboard, is attached.

Windows

Settings → System → Power & battery → Screen and sleep, and set When plugged in, put my device to sleep after to Never.

Or in a terminal, which does both at once:

powercfg /change standby-timeout-ac 0 powercfg /change monitor-timeout-ac 0

Closing the lid sleeps it too: Control Panel → Power Options → Choose what closing the lid does, set the plugged-in column to Do nothing.
