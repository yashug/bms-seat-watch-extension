Seat Watch

Watches a BookMyShow seat map and pings you the moment a block of seats opens up next to each other.

A big release is never as sold out as it looks. Cinemas hold seats back — for distributors, for staff, for whoever might still call — and when nobody calls, those seats go back on sale, often in the last hours before the show. Nobody announces it. That's the window this is for, along with the simpler case of wanting that screen and no other.

Searching by film works too

One film across every cinema in the city, with the same + on each showtime. It's the route most people take, and most of the time it's all you need.

No + on a showtime? Reload the page. Clicking through from a film's page doesn't reload it, and a reload is usually all it takes. If they still don't appear, open that cinema and add it from there — the cinema listing is the steadier of the two, and worth going straight to when a show is close to selling out and you'd rather not find out the hard way.

Or paste a seat-map address yourself — open the showtime until you can see the seats, then copy the address bar.

What counts as worth telling you about

Used for any show that leaves these blank. Position is the one that decides whether an alert is worth acting on — four free seats in the front corner and four dead centre are the same row length, and only one is worth going for.

How often it checks

Every show runs on its own clock. The closer it gets to starting, the more often its seat map is read — so a screening tonight is watched hard while one next week is barely touched. These bands apply to all your shows.

Each interval gets up to 15% of random slack, and shows are staggered a couple of seconds apart, so checks never land in lockstep. A show retires 15 minutes after it starts. Nothing checks more than once a minute — every check is a real page load in a real browser, and a tight loop is what gets an extension blocked.

Keep the machine awake

None of the above happens while the machine is asleep, and the release you're waiting for tends to land late in the evening — exactly when a laptop has nodded off. Keep the display on too: Chrome treats a window it thinks nobody can see much like a minimised one. Plug in first; both recipes assume it.

macOS

Run this in Terminal and leave the window open. Ctrl-C ends it, and so does closing the window — nothing is left switched on afterwards.

caffeinate -dis

Or, without the Terminal: System Settings → Lock Screen, set Turn display off on power adapter when inactive to Never, and check Battery → Options for Prevent automatic sleeping.

Closing the lid still sleeps a Mac, whatever else you set — unless a display, or power and an external keyboard, is attached.

Windows

Settings → System → Power & battery → Screen and sleep, and set When plugged in, put my device to sleep after to Never.

Or in a terminal, which does both at once:

powercfg /change standby-timeout-ac 0 powercfg /change monitor-timeout-ac 0

Closing the lid sleeps it too: Control Panel → Power Options → Choose what closing the lid does, set the plugged-in column to Do nothing.

Webhook

Optional — desktop notifications work on their own. This is the quickest way to get alerts onto your phone: one address, no bot to create.

A Discord channel webhook or an ntfy.sh topic both work as they are; anything else receives plain JSON. Chrome asks permission to reach the address the first time you save it.
